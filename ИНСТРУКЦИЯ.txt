English Tracker: сайт и телефон

ЧТО ЗДЕСЬ
index.html, manifest.webmanifest, service-worker.js и три иконки. Это сайт целиком. Он же открывается на телефоне как приложение.

1. ВЫЛОЖИТЬ САЙТ БЕСПЛАТНО (GitHub Pages)
  1. Зарегистрируйся на https://github.com (нужна почта).
  2. Нажми «New repository». Название: english-tracker. Тип: Public. Create repository.
  3. Нажми «uploading an existing file», перетащи сюда ВСЕ файлы из этой папки, нажми «Commit changes».
  4. Settings, затем Pages. В Source выбери «Deploy from a branch», ветка main, папка / (root), Save.
  5. Через 1-2 минуты наверху страницы появится адрес:
       https://ТВОЙ_ЛОГИН.github.io/english-tracker/
  Репозиторий публичный, значит ссылку может открыть кто угодно, но каждый увидит только свои данные: они хранятся у него на устройстве.

2. КАК ОБНОВЛЯТЬ
  Когда я пришлю новый index.html: открой репозиторий, Add file, Upload files, перетащи новый index.html, Commit changes.
  Через 1-2 минуты сайт обновится. Программа на ПК подхватит обновление при запуске или по кнопке «Обновить сейчас».

3. ТЕЛЕФОН
  Android (Chrome): открой адрес сайта, меню (три точки), «Установить приложение» или «Добавить на главный экран».
  iPhone (Safari): открой адрес, «Поделиться», «На экран Домой».
  Появится значок, и сайт будет открываться как отдельное приложение, даже без интернета (с последними данными).
  Напоминания: на телефоне они пока не работают, когда приложение закрыто. Для этого нужен сервер, это отдельный шаг.

4. ЕСЛИ GITHUB ПЕРЕСТАНЕТ ОТКРЫВАТЬСЯ
  Те же файлы можно загрузить на любой обычный хостинг (Timeweb, Beget и т.п., примерно 200-400 руб. в месяц). Просто загрузи их в корневую папку сайта.
  Адрес поменяется, его надо будет обновить в config.json программы.

5. ПОКА ДАННЫЕ ХРАНЯТСЯ НА КАЖДОМ УСТРОЙСТВЕ ОТДЕЛЬНО
  Сайт в браузере, программа и телефон пока не видят записей друг друга. Это решит следующий шаг: общая база (Supabase), вход по почте.
  Чтобы перенести данные вручную: «Сохранить копию данных» на одном устройстве, «Загрузить копию» на другом.
